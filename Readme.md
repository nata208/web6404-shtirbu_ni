## Лабораторная работа № 4

**Тема:** Современный CSS и основы ООП на JavaScript
**Технологии:** HTML, CSS, JavaScript

### Описание

Модернизация web-сайта из лабораторной работы № 2 с использованием Flexbox, Grid, CSS-переменных, CSS-анимации, методологии БЭМ, формы и класса на JavaScript для вывода данных в консоль

**Структура:**
- `lab4/index.html` — главная страница (вёрстка на Flexbox)
- `lab4/collections.html` — коллекции бренда (вёрстка на CSS Grid и анимация появления карточек)
- `lab4/table.html` — таблица «Иконы стиля»
- `lab4/beauty.html` — парфюмерия и косметика
- `lab4/auth.html` — страница входа и подписки с формой
- `lab4/css/style.css` — файл стилей 
- `lab4/js/app.js` — класс `ClientSubmission` и обработчик отправки формы
- `lab4/images/` — папка с изображениями
