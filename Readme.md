## Лабораторная работа №2
**Тема:** Сайт на тему Dolce & Gabbana  
**Технологии:** HTML, CSS  

### Описание
Многостраничный сайт (4 страницы) о модном доме Dolce & Gabbana.

**Структура:**
- `lab2/index.html` — главная страница
- `lab2/collections.html` — коллекции бренда
- `lab2/table.html` — таблица «Иконы стиля»
- `lab2/beauty.html` — парфюмерия и косметика
- `lab2/style.css` — файл стилей
